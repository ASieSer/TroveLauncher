Appearance

The club theme sets the accent. Pick None to choose your own colour again.

A club theme swaps the launcher's mark and name for the club's and fixes the accent to its colour; tint strength stays yours. The accent tints every surface and marks the primary action and live states, and at 0% tint the interface is neutral grey.

PTS

Repair re-downloads the whole manifest. It never deletes files, so your mods stay untouched.

On launch

Auto-relog is per account, with the loop button on its row: it signs that account back in whenever its game closes — a crash, or the server dropping you for being idle — but never when you stop it from here. If the crash left Trove's reporting window open, it is closed too. The Glyph option only changes the process ancestry and needs GlyphClientApp.exe already running.

Wine

Trove is a Windows game, so on Linux it lives inside a Wine or Proton prefix and can only be handed its ticket from in there. Leave both empty and they are worked out on their own: the prefix from the game folder you picked, the binary from your PATH. Point them somewhere else to use a different runner — Proton's own wine lives under dist/bin/wine.
