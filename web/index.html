On launch

Accounts themselves are always stored. This only covers the password, encrypted with Windows DPAPI so only this Windows user on this machine can read it. Without it you must retype it once the Trion session expires (~48h), and auto-relog cannot work at all — a background relaunch has no way to ask you for it.

Auto-relog is per account, with the loop button on its row. The Glyph option only changes the process ancestry and needs GlyphClientApp.exe already running.
