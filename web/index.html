Wine

        

            

            

            

                
                
            

            

            

                
                
            

            
Trove is a Windows game, so on Linux it lives inside a Wine or
                Proton prefix and can only be handed its ticket from in there. Leave both
                empty and they are worked out on their own: the prefix from the game folder
                you picked, and the runner from that prefix - a Proton prefix is launched
                with its own Proton, which is also the build that carries what Trove's
                anti-cheat loader needs. Only if the prefix says nothing does the Wine in
                your PATH get used.
